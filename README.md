# 썸네일 제작기 (Claude + ChatGPT)

클로드 코드에게 "썸네일 만들어 줘"라고 하면, 클로드가 ChatGPT 이미지 모델로 썸네일을 만들어 줍니다.
API 키 없이, 쓰고 계신 **ChatGPT 유료 구독(Plus 이상)** 사용량으로 만듭니다.

## 설치

이 저장소 링크를 **클로드 코드**(클로드 데스크톱 앱의 Code 탭 또는 터미널)에 붙여 넣고 이렇게만 말하세요.

```
이 링크의 썸네일 제작기 세팅해 줘
```

클로드가 아래 '클로드가 할 일' 순서대로 설치합니다. 사용자가 직접 할 일은 ChatGPT 로그인뿐이고, 이미 로그인돼 있으면 그것도 건너뜁니다.

준비물: 클로드 코드, ChatGPT 유료 구독, Node.js(없으면 클로드에게 설치해 달라고 하면 됩니다)

## 처음 사용할 때

설치 직후에는 채널 스타일이 비어 있습니다. 클로드가 먼저 물어봅니다.

1. 채널 이름
2. **참고할 썸네일 2~6장**: 이런 느낌으로 만들고 싶은 썸네일입니다. 내 채널 썸네일이 가장 좋고, 없으면 같은 분야 채널의 썸네일을 참고용으로 쓰세요(그대로 베끼지 않습니다).
3. 클로드가 썸네일을 보고 규칙(배경, 글자 줄 수·색·위치 등)을 정리해 보여 줍니다. 고칠 부분만 말하면 됩니다.

한 번 정해 두면, 다음부터는 따로 설명하지 않아도 그 스타일로 만듭니다.

## 사용

- "이번 영상 썸네일 문구 추천해 줘"
- "문구는 '○○○'로 썸네일 만들어 줘"
- "그림은 그대로 두고 아랫줄 글자만 바꿔 줘"
- "쇼츠용 세로 썸네일도 만들어 줘"

결과는 `output/<날짜>/` 폴더에 저장됩니다. 채널을 여러 개 운영하면 채널마다 스타일을 따로 만들 수 있습니다.

## 참고

- 이미지 생성은 일반 대화보다 ChatGPT 구독 사용량을 더 씁니다.
- 1장에 약 1분 걸립니다. 여러 장을 동시에 만들어도 시간은 비슷합니다.
- 다른 사람의 썸네일이나 로고를 참고할 때는 저작권과 상표권에 주의하세요.

## 클로드가 할 일 (설치 순서)

사용자가 이 저장소 링크를 주며 세팅을 요청하면 아래 순서로 진행한다.

1. **내려받기**: 사용자 홈 아래 `thumbnail-maker` 폴더(Windows `%USERPROFILE%\thumbnail-maker`, macOS `~/thumbnail-maker`)로 이 저장소를 `git clone`한다. Git이 없으면 저장소 ZIP을 내려받아 같은 위치에 푼다. 이미 있으면 `git pull`로 최신화한다.
2. **Node.js 확인**: `node --version`. 없거나 18 미만이면 사용자 동의를 받아 설치한다(Windows는 `winget install OpenJS.NodeJS.LTS`, macOS는 `brew install node` 또는 nodejs.org 설치 파일).
3. **Codex CLI 확인**: `codex --version`. 없으면 `npm install -g @openai/codex`로 설치한다.
4. **설치 스크립트 실행**: 내려받은 폴더에서 `node install.mjs`. 스킬을 `~/.claude/skills/thumbnail-maker/`에 등록하고, 마지막 줄 JSON으로 Codex·로그인·채널 스타일 상태와 남은 할 일(`next`)을 알려 준다.
5. **로그인**: `login`이 `needed`이면 사용자에게 터미널에서 `codex login`을 직접 실행해 달라고 한다. 비밀번호나 인증 코드는 Claude가 입력하지 않는다. 로그인 뒤 `node install.mjs`를 다시 실행해 `ok`인지 확인한다.
6. **끝나면**: 설치 결과를 한두 줄로 알리고, 바로 이어서 `SKILL.md`의 '처음 사용할 때' 순서로 채널 이름과 참고할 썸네일을 요청한다.
